To stream real metrics from your server, run the monitoring agent. It reads CPU, RAM and disk usage every 5 seconds and sends them here.

Step 1 — Generate an API key and add a node

Go to the Manage tab, create an API key and add a node. Note down both values — you will need the API key (shown once after creation) and the Node ID (shown below the hostname in the Nodes list).

Step 2 — Install the dependency

macOS / Linux
Windows
pip3 install psutil

If pip3 is not found:

python3 -m pip install psutil

Step 3 — Download and run the agent

Open your terminal and run these two commands:

curl -sSL https://metrics-nginx-freddy.fly.dev/static/agent.py -o agent.py
python3 agent.py --url https://metrics-nginx-freddy.fly.dev --key YOUR_API_KEY --node YOUR_NODE_ID

You will see your metrics printing in the terminal. Switch to the Live Metrics tab to watch the charts update in real time.

Keep it running after closing the terminal

If you want the agent to keep running in the background (e.g. on a server):

nohup python3 agent.py --url https://metrics-nginx-freddy.fly.dev --key YOUR_API_KEY --node YOUR_NODE_ID > agent.log 2>&1 &

Requires Python 3.8+ installed and added to PATH. If you don't have Python, download it from python.org — make sure to check "Add Python to PATH" during installation.

pip install psutil

If pip is not found:

python -m pip install psutil

Step 3 — Download and run the agent

Open Command Prompt or PowerShell and run these two commands:

curl -sSL https://metrics-nginx-freddy.fly.dev/static/agent.py -o agent.py
python agent.py --url https://metrics-nginx-freddy.fly.dev --key YOUR_API_KEY --node YOUR_NODE_ID

You will see your metrics printing in the terminal. Switch to the Live Metrics tab to watch the charts update in real time.

Keep it running after closing the terminal

Run in the background using PowerShell:

Start-Process python -ArgumentList "agent.py --url https://metrics-nginx-freddy.fly.dev --key YOUR_API_KEY --node YOUR_NODE_ID" -WindowStyle Hidden
